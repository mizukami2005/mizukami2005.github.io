プライバシーポリシー

対象アプリ：Strolloria（iOS／Android）

English version

Strolloriaは、許可をいただいた場合に限り、HealthKitまたはHealth Connectから当日の歩数合計を読み取ります。 歩数、歩行履歴および街の進行データは端末内に保存され、Firebaseを含む外部サービスには送信されません。 アプリの品質改善のため、健康情報を含まない利用状況、クラッシュ情報および性能情報をGoogleのFirebaseへ送信します。

本プライバシーポリシーは、Mizukami Takamasa（以下「運営者」といいます。）が提供するアプリ 「Strolloria」（以下「本アプリ」といいます。）における情報の取扱いについて説明するものです。

1. 本アプリがアクセスまたは保存する情報

歩数情報

  • iOSではApple HealthKit、AndroidではHealth Connectから取得する当日の歩数合計
  • 歩数を本アプリ内の街の成長や歩行履歴に反映するために生成される日別歩数記録

本アプリが歩数にアクセスするのは、利用者がOSの権限画面で読み取りを許可した場合のみです。 初回連携時に読み取るのは、その日の午前0時から現在時刻までの歩数合計だけであり、連携前の過去日の歩数は取得しません。 以後は、本アプリの起動時、連携完了時およびフォアグラウンド復帰時などに当日の歩数合計を読み取ります。 本アプリはHealthKitまたはHealth Connectへ健康データを書き込みません。

本アプリ内で生成・保存される情報

  • 選択した街、街の成長段階、旅の進行、完成記録および周回記録
  • 日別の歩数履歴および街の成長履歴
  • オンボーディングの完了状態、言語設定その他のアプリ設定

端末の設定情報

本アプリは、表示言語、日付および時刻を、言語表示、日付ごとの歩数管理ならびに街の明るさや天候の自動表現に利用します。 正確な位置情報、氏名、住所、電話番号または連絡先は取得しません。

Firebaseを通じて取得・外部送信する情報

本アプリは、品質の把握および改善のため、Google LLCが提供するGoogle Analytics for Firebase、Firebase Crashlyticsおよび Firebase Performance Monitoringを利用します。これらのサービスにより、次の情報が自動的に取得され、Googleへ送信されることがあります。

  • 利用状況：アプリの起動、画面表示、セッション、機能の利用状況、アプリのバージョン、OS、端末の機種、言語、タイムゾーン、 IPアドレスから推定される国または地域、およびアプリのインストールごとに生成される仮名のアプリインスタンスID
  • クラッシュ・不具合情報：クラッシュまたは例外の発生日時、スタックトレース、例外メッセージ、アプリの状態、ログ、アプリのバージョン、 OS、端末の機種・性能・空き容量等の状態、Firebase Installation ID、Crashlytics Installation UUIDおよびセッションID
  • 性能情報：起動時間、画面描画時間、処理時間、CPU・メモリ使用状況、ネットワークの種類、通信先URL（クエリパラメータおよび通信内容を除きます。）、 応答時間、応答コード、送受信データ量、アプリのバージョン、OS、端末の機種、IPアドレスから推定される国または地域、 Firebase Installation IDおよびセッションID

本アプリは、歩数、HealthKitまたはHealth Connectから取得した情報、日別の歩行履歴、街の進行・完成・周回記録を、 Firebaseのイベント、ユーザープロパティ、クラッシュログ、カスタムキー、性能トレースその他の送信項目に含めません。 また、広告識別子（AppleのIDFAおよびAndroidの広告ID）を取得せず、Firebaseの情報を広告配信、広告のパーソナライズまたはアプリをまたぐ追跡に利用しません。

お問い合わせ時に提供される情報

利用者がメールでお問い合わせを行った場合、メールアドレス、メール本文および利用者が任意に提供した情報を受け取ります。

2. 情報の利用目的

本アプリおよび運営者は、前項の情報を次の目的に限って利用します。

  • 歩数に応じて街を成長させ、本アプリの主要機能を提供するため
  • 日別の歩数、街の成長、完成および周回の記録を端末上で表示・維持するため
  • 利用者が選択した言語および設定を反映するため
  • データの重複計上を防ぎ、歩数同期と街の進行を正しく保つため
  • 利用状況を統計的に把握し、画面構成、機能および操作性を改善するため
  • クラッシュおよび不具合を検知・分析し、原因の調査と修正を行うため
  • 起動時間、画面描画および通信等の性能を測定し、安定性と応答性を改善するため
  • お問い合わせへの回答および不具合の調査のため
  • 法令上必要な対応を行うため

歩数情報を、広告、マーケティング、利用者の追跡、信用評価、保険料の算定または第三者によるデータ分析には利用しません。

3. 保存場所、外部送信および保存期間

  • 歩数履歴、街の進行記録およびアプリ設定は、本アプリ専用の端末内ストレージに保存します。
  • 歩数、歩行履歴および街の進行記録を、運営者が管理するサーバーまたはFirebaseへ送信・保存することはありません。
  • 端末内の情報は、本アプリを削除するまで保存されます。
  • 端末のOSバックアップ設定によっては、端末内データがAppleまたはGoogleのバックアップ対象となる場合があります。バックアップの管理および削除は、各OSの設定から行ってください。
  • Google Analyticsのユーザー単位およびイベント単位のデータは、取得から14か月で自動削除されるよう設定します。 この保存期間の設定は、標準の集計レポートには適用されない場合があります。
  • Firebase Crashlyticsのクラッシュ情報および関連する識別子は、Googleが90日間保持した後、稼働中およびバックアップのシステムから削除する処理を開始します。
  • Firebase Performance Monitoringは、IPアドレスに関連付けられた性能イベントを30日間、Firebase Installation IDに関連付けられた情報および 匿名化された性能情報を60日間保持した後、稼働中およびバックアップのシステムから削除する処理を開始します。
  • お問い合わせに含まれる情報は、対応、記録および法令遵守に必要な期間保存した後、不要になった時点で削除します。

4. 第三者提供および外部サービス

運営者は、本アプリが端末内に保存する歩数情報や進行記録を取得せず、第三者へ提供または販売しません。 Firebaseに送信される情報は、運営者の委託先としてGoogleが処理します。 このほか、法令に基づく開示要請への対応、人の生命・身体・財産の保護、または業務委託に必要な場合には、適用法令に従って情報を取り扱うことがあります。

本アプリおよび本ポリシーに関連して、次の外部サービスが利用されます。

  • Apple HealthKit／Google Health Connect：利用者の許可に基づく歩数の読み取りに利用します。健康データ自体は各サービスと端末の管理下にあります。
  • Google Analytics for Firebase（提供者：Google LLC）：アプリの利用状況を統計的に分析し、機能および操作性を改善するために利用します。
  • Firebase Crashlytics（提供者：Google LLC）：クラッシュおよび不具合を検知・分析し、安定性を改善するために利用します。
  • Firebase Performance Monitoring（提供者：Google LLC）：起動、描画、処理および通信の性能を測定・分析し、応答性を改善するために利用します。 Firebaseによる情報の取扱いについては、 Firebaseのプライバシーとセキュリティおよび Googleプライバシーポリシー をご確認ください。
  • GitHub Pages：本ポリシーの公開に利用します。閲覧時のIPアドレス、ブラウザ情報、アクセス日時等をGitHubが処理する場合があります。詳細は GitHubのプライバシーステートメント をご確認ください。
  • メールサービス：お問い合わせメールの送受信に利用します。メールの取扱いには、利用者および運営者が利用するメールサービス提供者の方針が適用されます。

Firebaseへ送信される情報は、Google LLCおよびその委託先が、日本国外を含むGoogleまたはその代理人の施設が所在する国・地域で処理または保存する場合があります。 Googleは、Firebaseのデータ処理・セキュリティ条件および適用されるデータ保護法に基づいてこれらの情報を取り扱います。

5. 安全管理

本アプリは、歩数履歴や進行記録をOSが提供するアプリ専用領域に保存し、他のアプリから直接アクセスできないようにします。 また、取得する健康データを歩数合計に限定し、読み取り専用の権限のみを要求することで、取扱う情報を必要最小限にします。 Firebaseへ送信する情報から歩数その他の健康情報を分離し、運営者によるFirebase管理画面へのアクセスを必要な範囲に制限します。 Firebaseとの通信にはHTTPSが使用され、対象のFirebaseサービスでは保存時の暗号化が行われます。

6. 利用者による管理と削除

  • 歩数へのアクセス許可は、iOSの「ヘルスケア」または設定、AndroidのHealth Connectの設定から、いつでも確認・取消しできます。
  • 許可を取り消すと、本アプリは以後の歩数を読み取れなくなります。取消し前に端末内へ保存された履歴や街の進行は、自動では削除されません。
  • 本アプリ内に保存された情報は、本アプリを端末から削除することで削除できます。OSバックアップ内のデータは、各OSまたはクラウドサービスの設定から別途削除してください。
  • HealthKitまたはHealth Connectに保存されている元の歩数データは、本アプリを削除しても削除されません。各サービスの設定から管理してください。
  • 本アプリを削除すると、その端末からFirebaseへの新たな送信は停止します。再インストールした場合は、原則として新しいアプリインスタンスID等が生成されます。

本アプリには利用者アカウントがなく、運営者のサーバーに歩数や進行記録を保存していないため、運営者が遠隔でこれらの端末内データを参照または削除することはできません。

適用法令によりFirebaseによる情報取得に事前の同意が必要な場合、本アプリは同意を得るまで対象サービスによる取得を開始しません。 同意の撤回、Firebaseへ送信された情報の削除その他のデータ保護上の権利行使を希望する場合は、下記のお問い合わせ先へご連絡ください。 本アプリには利用者アカウントがないため、ご申告いただいた情報とFirebase上の仮名データを特定して対応できない場合があります。 その場合も、合理的に可能な範囲で対応方法をご案内します。
