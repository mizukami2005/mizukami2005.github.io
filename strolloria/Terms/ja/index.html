Strolloria 利用規約

この利用規約（以下「本規約」といいます。）は、Mizukami Takamasa（以下「提供者」といいます。）が提供するアプリケーション「Strolloria」（以下「本アプリ」といいます。）の利用条件を定めるものです。

本アプリをダウンロード、インストールまたは利用した方（以下「ユーザー」といいます。）は、本規約および プライバシーポリシー の内容に同意したものとみなされます。同意いただけない場合は、本アプリを利用しないでください。

第1条（適用）

  1. 本規約は、本アプリの利用に関する提供者とユーザーとの間の一切の関係に適用されます。
  2. 提供者が本アプリ内または公式ウェブサイト上に掲載する注意事項、ガイドラインその他の個別規定は、本規約の一部を構成します。
  3. 本規約と個別規定の内容が異なる場合は、個別規定に特段の定めがない限り、個別規定が優先して適用されます。
  4. ユーザーが未成年者である場合は、親権者その他の法定代理人の同意を得たうえで本アプリを利用してください。

第2条（本アプリの内容）

  1. 本アプリは、端末から取得した歩数に応じて街を成長させ、散歩や日々の歩行を楽しむためのアプリです。
  2. 本アプリは、歩数、街の成長段階、旅の履歴、都市の完成記録、周回数その他の情報を表示または保存する機能を提供します。
  3. 本アプリ内の街、成長段階、スタンプ、完成記録その他の仮想的なコンテンツには、現実の金銭的価値はなく、換金、譲渡、売買または本アプリ外での利用はできません。
  4. 提供者は、ユーザーに対し、本規約に従って個人的かつ非商業的な目的で本アプリを利用するための、限定的、非独占的かつ譲渡不能な権利を許諾します。

第3条（歩数情報および健康に関する注意）

  1. 本アプリは、ユーザーの許可を得たうえで、Appleのヘルスケア機能、HealthKit、AndroidのHealth Connectその他の端末またはOSが提供する機能から歩数情報を読み取ることがあります。
  2. 本アプリは、歩数情報を健康管理、医療行為、診断、治療、予防または医学的助言のために提供するものではありません。
  3. 端末、ウェアラブル機器、OS、権限設定、同期状態その他の事情により、歩数が遅れて反映される場合や、実際の歩数と異なる場合があります。提供者は、歩数情報の正確性、完全性または即時性を保証しません。
  4. ユーザーは、周囲の状況、交通、天候および自身の体調に十分注意し、安全を最優先して本アプリを利用してください。歩行中に画面を注視するなど、危険を伴う方法で利用しないでください。
  5. 体調に不安がある場合または異常を感じた場合は、歩行を中止し、必要に応じて医師その他の専門家に相談してください。

第4条（無料機能）

  1. 本アプリの基本機能および提供者が無料対象として指定する都市は、サブスクリプションへ加入せずに利用できます。
  2. 無料ユーザーは、無料対象の都市を完成させた後も、対象都市を選択して新しい旅を開始し、再び成長させることができます。
  3. 提供者は、本アプリの継続的な提供および改善のため、無料機能の内容、表示または利用条件を合理的な範囲で変更する場合があります。

第5条（Strolloria Pass）

  1. 本アプリでは、有料の自動更新サブスクリプション「Strolloria Pass」（以下「本サブスクリプション」といいます。）を提供する場合があります。
  2. 本サブスクリプションの有効期間中、ユーザーは、購入画面に表示される内容に従い、次のような機能を利用できます。
    • Strolloria Pass対象として提供される都市の利用
    • 将来追加されるStrolloria Pass対象のTown Packの利用
    • 対象となるすべてのFeatured Destinationからの目的地選択
    • 街の時間帯および天候を手動で変更する機能
    • その他、購入画面でStrolloria Passの特典として表示される機能
  3. 本サブスクリプションで提供される最新の機能、料金、契約期間その他の条件は、購入時に本アプリ、App StoreまたはGoogle Playに表示される内容をご確認ください。
  4. 提供者は、将来追加される都市、Town Packその他のコンテンツについて、具体的な追加時期、追加数または更新頻度を保証しません。
  5. 本サブスクリプションが終了した場合、有料機能へのアクセスは停止します。端末内に保存された街の完成記録などが直ちに削除されるとは限りませんが、終了後も表示または再利用できることを保証するものではありません。

第6条（購入、自動更新、解約および返金）

  1. 本サブスクリプションの購入代金は、ユーザーが利用するApp StoreまたはGoogle Playのアカウントに請求されます。
  2. 本サブスクリプションは、ユーザーが次回更新日の所定の期限までに解約しない限り、自動的に更新されます。更新時には、選択した契約期間に応じた料金が請求されます。
  3. 解約は、本アプリの削除では完了しません。ユーザー自身でApp StoreまたはGoogle Playのアカウント設定から手続きを行う必要があります。
    • Apple： サブスクリプションの管理
    • Google Play： 定期購入の管理
  4. 解約後も、原則として、既に支払い済みの契約期間が終了するまでは本サブスクリプションを利用できます。
  5. 購入、請求、解約および返金には、App StoreまたはGoogle Playの規約および返金方針が適用されます。法令上必要な場合を除き、提供者が独自に返金を行うものではありません。
